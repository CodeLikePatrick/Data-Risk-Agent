# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-13

### Added

- Synthetic e-commerce data generator with injected address, price, text, and group risks
- Two-stage detection engine: interpretable rules + numpy logistic regression
- ReAct review agent with tools, structured verdicts, and an OpenAI-compatible client
- Offline deterministic policy for reproducible evaluation
- Engine and agent evaluation with precision, recall, F1, and false-positive rate
- README, rule knowledge base, and design documentation
